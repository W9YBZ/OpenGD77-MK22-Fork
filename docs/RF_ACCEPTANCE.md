# 人工实机验收方案（本次未执行）

当前没有可交付的完整链接固件，MDC RF 后端也未实现。以下是后续验收步骤，
不是本次已经完成的测试。不得用主机 WAV 的解码结果替代 RF 记录。

1. 先恢复可复现的 R20260131 GD-77 MCUXpresso 构建：保留官方编译参数、
   段布局和编解码器占位策略，确认本分支新增代码参与编译并检查 map。
   不更改全局 PIT、bootloader、Codeplug 或校准布局。解决 GPL 主机模块与
   固件许可证边界后，才考虑加入 MDC 编码器；目前固件没有隐藏 RF 开关。
2. 由操作者决定是否手工刷入经过完整构建审核的实验版本。本任务不提供自动
   刷机命令。准备已备份的官方 R20260131、CPS E2026.05.26.01 和用户数据。
   在测试前记录当前 Zone/Channel/VFO、DMR ID、音量、功率、CSS、校准摘要。
3. 通过合规低功率、假负载/屏蔽/衰减耦合装置测试，保护 SDR 输入不受 PA
   直连损坏；由操作者确认合法频率和测试环境。先测 FM Off、Beep 和本地
   Talk Permit，暂不尝试 MDC RF。
4. Off：正常手动 PTT 松开后无新增尾音；Beep：SDR 解调后测到约 1000 Hz、
   150 ms 且只一次，确认确实发生于 RF carrier 关闭之前。本机扬声器声音
   不作为证据。分别测窄带/宽带、VHF/UHF、TX CSS=无/CTCSS/DCS。
5. Talk Permit：有效 FM 启动时，近场音频测到三声 940 Hz/40 ms，中间
   10 ms 间隔；同时录制 RF 解调音频，确认没有这组三声经 MIC/电路串入。
   观察寄存器 3A 的 MIC 关闭和恢复；10 ms speaker drain 保护值须以实测
   缓冲/声学衰减确认。Off、silent、channel no-beep、VOX-enabled 不播放。
6. 每个模式至少测试 20 次正常收发，再测短于提示音的 PTT、快速反复重按、
   1750 Hz 后释放、DTMF 后释放、TOT（含尾音期间临界超时）、RX-only、
   禁发频率、TX 失败模拟、DMR、APRS PTT Beacon/自动 Beacon、卫星。
   检查无重复 EOT、错误尾音、卡 TX、界面锁死或 MIC 永久静音。
   VOX-enabled 的手动 PTT 也保守禁用新增效果；这是明确的隔离策略。
7. 在正常和故障结束后，比较寄存器 35/41/79/3A、MIC 路径、RF amp/mux、
   CSS、滤波、功率及信道设置。I²C 持续故障时不能保证寄存器恢复成功；
   应观察错误路径关闭 PA/返回 RX，禁止继续误发。不要写入校准“修复”幅度。
8. 菜单逐项确认/取消、QuickKey 增减及超时确认；ID 检查 0001/1234/FFFF
   与循环边界。确认保存后断电仍在，取消恢复旧值，之后修改 DMR ID 不会
   静默覆盖已保存 MDC ID。`MDC1200*` 当前应只返回 RX，无 MDC 尾帧。
9. 用 CPS 实际读写，再读取对比 Codeplug/校准和原设置；仅源代码布局测试
   不能证明 CPS 实机兼容。回退官方固件后，确认原设置仍正确。

## 后续 MDC RF 必须满足的证据

首先按协议文档验证独立采样时钟/DMA 到 AT1846 调制输入的实际硬件通路；
C6000 本机扬声器输出和控制 PA 的 MCU DAC 均不能直接当作可用 RF 通路。
记录启动/结束稳态、频偏、电平、预加重/滤波处理和每个改变寄存器的恢复。

用 RTL-SDR/其他 SDR 记录 IQ；同时保存未经音频压缩、未去加重/去加重参数
明确的解调 WAV。独立 Kaufman 解码器输出 raw op/arg/ID 和 CRC 接受结果；
再用 sdrtrunk/商用兼容接收机确认 ANI/EOT（POST-ID）事件含义。
本实现候选为 op=01/arg=00，不能仅以 op=00/arg=80 的网页预设替代证据。

每个 ID 0001/1234/FFFF 至少 20 次，逐次记录：固件 SHA、信道/带宽/功率/
CSS、仪表设置、IQ/WAV SHA256、解码器版本、op/arg/ID、CRC/纠错状态、
实测 baud、1200/1800 Hz、符号边界抖动、频偏和成功/失败。首次目标为
可控良好信号环境 20/20 正确 ID 和 POST-ID、无重复/伪帧；该门槛是本项目
验收建议，不是标准公布的容差。失败时保留所有捕获，不挑选一次成功报 Pass。

定位顺序：比对编码字节/CRC/FEC → PCM 与参考解码 → 时钟/符号时序 →
切音相位/瞬态 → RF 通路/电平/频偏 → CSS/滤波影响。没有真实 RF 外部解码
证据，MDC RF 一律保持 Blocked/Not Run，不能称“已修复”或“兼容”。

## 回退

由用户手工刷回已验证的官方 R20260131。新增配置只在原 settings 的两个
未用字中，官方忽略；magic、长度、原字段位置均不变。官方恢复默认设置会
清零扩展槽，重新进入本分支时采用 Off/On/非零 DMR low16 默认值。
不需要自动恢复/擦写 EEPROM 或校准。如发现数据差异，停止实验并由用户
依据备份人工处理；本任务不操作任何电台硬件。
